# Chess Tracker Dashboard

A full-featured web application to track Chess.com player profiles, stats, recent games and also play a built-in chess game with Chess.com-style pieces.
The project includes a **React** frontend with **Tailwind** **CSS**, **Recharts**, and a **Node.js/Express** backend for handling Chess.com API requests..

## Features

- Search Chess.com usernames to view profiles
- View detailed stats (rapid, blitz, bullet ratings, win/loss records)
- See recent games with opponents and results
- Interactive charts for rating progression
- Fully responsive UI with Tailwind CSS

## Ratings Dashboard

-Interactive rating comparison chart
-Clean and responsive UI
-Stats fetched through backend proxy

## Tech Stack

- **Frontend:** React, Tailwind CSS, Recharts, Axios
- **Backend:** Node.js, Express, Axios, CORS
- **Data Source:** Chess.com Public API

 ## Built-in Chess Game
-Play chess against a simple AI
-Drag-and-drop board
-Chess.com-style SVG pieces
-Automatic AI response move
-Restart game option
-Illegal move handling (prevents crashes)
