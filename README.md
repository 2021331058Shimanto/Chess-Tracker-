# Chess Tracker Dashboard

A web application to track chess players’ profiles, stats, and recent games using the Chess.com public API. This project includes a **React frontend** with **Tailwind CSS** for styling and a **Node.js/Express backend** for API proxying and data fetching.

## Features

- Search Chess.com usernames to view profiles
- View detailed stats (rapid, blitz, bullet ratings, win/loss records)
- See recent games with opponents and results
- Interactive charts for rating progression
- Fully responsive UI with Tailwind CSS

## Tech Stack

- **Frontend:** React, Tailwind CSS, Recharts, Axios
- **Backend:** Node.js, Express, Axios, CORS
- **Data Source:** Chess.com Public API
